市面上的 Windows 优化工具我试过不少，最后都放弃了，原因几乎一样：点几下之后系统确实"快"了一点，但**它到底改了什么、怎么改回去，你完全不知道**。注册表被改了哪几个键、服务被关了哪几个、计划任务删了哪些，全靠猜。真出问题时，唯一的办法是重装系统。

所以我写了 BaiWindowsTools——一个把"可逆"放在第一位的优化工具箱。每改一处，原值都记下来，随时能一项一项还原回去。

## 它是什么

一个模块化的 Windows 10/11 优化工具箱，分两层：

- **PowerShell 引擎**：真正动手改系统的那一层，负责执行模块、记录回滚账本、创建还原点；也能脱离界面单独运行。
- **WPF 桌面应用**：只做界面和调度，以普通权限运行；需要写入系统设置时，通过命名管道把请求交给独立的特权执行服务。

这样设计的原因是界面层不应该持有系统写入权限。应用本身始终以普通权限跑着，敏感操作是经过一次明确的授权（UAC）后由特权服务完成的。

## 核心特性

**开箱可用的模块库**

- 优化模块 60 项、系统自定义 39 项，合计 99 项，分 12 个功能分类
- 9 个配置预设，覆盖隐私保护、关闭 AI 相关功能、游戏优化等场景
- 另有资源管理器、任务栏、游戏与显卡、系统功能等专项预设包
- 界面与外观分类下提供 24 项自定义，手感相关的东西也能逐项调

**每一项改动都可追溯、可还原**

- 事务账本 v2：原子写入 + 逐项 `.bak` 备份 + 命名 Mutex 防止并发冲突
- 账本损坏时采取 fail-closed 策略——宁可停下来报错，也不带着损坏的记录继续改系统
- 批量应用前自动创建系统还原点，出问题可以整体回退
- 每个操作都有稳定的 `operationId`，模块定义用 JSON 描述（`schemaVersion=2`），改动有据可查

**该谨慎的地方不省事**

- 启动时自动检测管理员权限，需要时通过 UAC 提权，不用手动右键"以管理员身份运行"
- 高风险模块不会静默执行，必须手动输入 `yes` 确认
- 每个模块都标注风险等级（低/中/高）与当前状态（已应用/部分应用/未应用/未知）

当前版本 **v0.1.0**，安装包 `BaiWindowsTools-0.1.0-x64-setup.exe`，约 69 MB，发布于 2026 年 9 月 18 日。

**安装步骤**：

1. 下载安装包，双击运行
2. 按向导提示完成安装
3. 首次启动会请求管理员权限，确认后进入主界面

不需要时可以直接在"应用和功能"里卸载。

> **关于 SmartScreen 提示**：当前安装包**没有做代码签名**（个人项目，签名证书成本较高），所以 Windows 可能弹出"Windows 已保护你的电脑"。这不是文件有问题，点击"更多信息"，再点"仍要运行"即可。

**校验安装包**：如果想确认文件完整，可以在安装前比对 SHA256：

```
Get-FileHash .\BaiWindowsTools-0.1.0-x64-setup.exe -Algorithm SHA256
```

v0.1.0 的 SHA256 是：

```
a2655e50221d3af841b83a7ba5afb6f94a94f64c153e4634af807dd7692ce593
```

**系统要求**：Windows 10 / 11（64 位）。引擎脚本、模块定义与配置文件随安装包一并部署，无需单独准备 Python 或 PowerShell 环境。修改系统设置时需要管理员权限。

## 关于可靠性

代码托管在 GitHub，可以自己审阅：<https://github.com/bai0131/BaiWindowsTools>

引擎支持只读预检，可以在**不修改任何设置**的前提下检查环境：

```
toolkit.ps1 -Validate
```

项目目前有 238 个测试用例（契约 41、执行主机 31、桌面应用 166），可以用 `dotnet test BaiWindowsTools.slnx -c Release` 复现。

## 写在最后

这个工具的设计前提是：**优化应该是可逆的**。任何让你"一键优化"却说不清改了什么、也不给你退路的工具，都不值得用。

如果你在使用中遇到问题、发现某个模块的回滚不干净，或者想要的选项还没有，欢迎到仓库提 issue。
