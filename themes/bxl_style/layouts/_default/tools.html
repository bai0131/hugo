安装包暂未做代码签名

Windows SmartScreen 可能提示「Windows 已保护你的电脑」。这是因为本项目的安装包未购买代码签名证书（个人项目成本较高），并非文件本身有问题。

继续安装的方法：在拦截提示窗口中点击「更多信息」，再点击「仍要运行」。

如需自行核对文件完整性，可在安装前用 PowerShell 执行 Get-FileHash .\{{ $t.filename }} -Algorithm SHA256，与下方校验值比对。

功能特性

12 分类 · 99 模块 · 9 预设

按隐私、外观、游戏、系统功能等分类组织，模块定义使用 JSON 描述（schemaVersion=2），每个操作都有稳定的 operationId。

预设包一键应用

内置隐私保护、关闭 AI 相关功能、游戏优化等预设组合，另含资源管理器、任务栏、游戏与 GPU、系统功能等专项预设包。

界面与外观自定义

UI 分类下提供 24 项外观调整，可在应用内直接修改并随时还原。

电源方案导入

内置 AMD 与 Intel 平台的电源方案文件（.pow），一键导入对应平台的最优电源计划。

权限自检测与 UAC 提权

启动时自动检测管理员权限，需要写入系统设置时通过 UAC 自动提权，无需手动右键以管理员身份运行。

事务账本 v2

每次修改都写入回滚账本：原子写入、逐项 .bak 备份、命名 Mutex 防止并发冲突，账本损坏时采取 fail-closed 策略而非盲目继续。

批量执行前自动创建还原点

在批量应用修改前自动创建系统还原点，出现问题可以直接回退到操作前的状态。

高风险操作二次确认

高风险模块不会静默执行，需要手动输入 yes 确认后才会应用。

架构与可信度

项目分为两层：一套负责实际修改系统的 PowerShell 引擎，和一个只做界面与调度的桌面应用。敏感写入不经过应用本身，而是交给独立的特权执行服务完成。

PowerShell 引擎

toolkit.ps1 配合 lib/ 与 config/，负责模块执行、回滚账本与还原点管理。也可以脱离界面单独运行，并支持只读预检。

WPF 桌面应用

以普通权限运行，通过命名管道与 session nonce 与特权执行服务通信，界面层不直接持有系统写入权限。

测试覆盖 238 个用例（契约 41 · 执行主机 31 · 桌面应用 166），可用 dotnet test BaiWindowsTools.slnx -c Release 复现。
