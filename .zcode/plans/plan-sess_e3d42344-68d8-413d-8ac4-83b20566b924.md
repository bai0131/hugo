## 页面结构
1. **产品头图区**：应用图标 + `BaiWindowsTools` + 「系统优化管理工具箱」+ tagline + 徽章（`v0.1.0`、`Windows 10/11 · x64`）。面板样式复刻站点现有写法（浅 `#EDE9E1` / 深 `#24262B`，圆角 16px）。
2. **下载区**：主按钮「下载安装包」（实色陶土红，无下方小字）；次按钮「查看全部版本」「浏览源码」；下方元信息行陈列版本、发布日期、支持系统、文件大小。
3. **未签名说明区块**：SmartScreen 会拦截，写明「更多信息 → 仍要运行」处置步骤、未签名的原因，以及可用 SHA256 自行校验；校验值做成可折叠一行。
4. **功能特性矩阵**（卡片网格）：12 分类 / 99 模块 / 9 预设；隐私、关闭 AI、游戏优化、资源管理器、任务栏、游戏与 GPU、系统功能预设包；UI 外观自定义 24 项；电源方案导入（AMD/Intel `.pow`）；UAC 自动提权；事务账本 v2（原子写入 + `.bak` + 命名 Mutex + 损坏 fail-closed）；批量执行前自动创建还原点；高风险模块需输入 `yes`。
5. **架构与可信度区块**：PowerShell 引擎 + WPF 应用两层结构，普通权限运行、命名管道 + session nonce 调用特权服务；测试规模 238 用例（契约 41 / 执行主机 31 / 桌面应用 166）。
6. **系统要求 + 安装步骤**：Windows 10/11 x64、三步安装、首次运行 UAC 提权、卸载方式、`toolkit.ps1 -Validate` 只读预检提示。
7. **界面截图区**：先搭图片位与自适应样式（仓库目前只有 HTML 设计稿，无 PNG，你提供后我替换）。
8. **页脚信息**：仓库链接、第三方声明（THIRD_PARTY_NOTICES 引用 optimizerDuck GPL-3.0、RyTuneX AGPL-3.0）。

## 样式方案
CSS 全部写在模板内联 `<style>`，**不碰 `style.css`**（照搬 `music.html` 的做法）。理由：该文件 3828 行且 `!important` 密布；交接文档警告过 BOM 损坏风险；内联块文档顺序靠后，同特异性下天然胜出，改动完全隔离。

双模式成对声明：浅色 `body.page-internal:not(.dark-mode)`、深色 `body.page-internal.dark-mode`。配色沿用站点既有值（浅：底 `#FAF8F5`、正文 `#111111`、次要 `#666666`、分隔 `#E5E0D8`、面板 `#EDE9E1`、边框 `#D9D2C5`、主色 `#C8654B`；深：底 `#18191C`、正文 `#E2E0D8`、次要 `#AAAAAA`、面板 `#24262B`、边框 `#33363D`、主色 `#E5866C`）。

**三个已探明的坑逐个规避：**
1. `style.css:2287` 对 `body/a/h1-h6/p/span/li/div` 强制 `color:#f5f5f5 !important`，而 `time`/`code`/`strong`/`em`/`small`/`button` 不在 3201、3699 的覆盖名单内——这些标签我必须显式给颜色，否则浅色模式下近乎不可见。
2. 不用 `var(--paper-*)` / `var(--text-*)`：这些 token 只在失效的 `body.dark` 块里重定义过，深色模式会渲染出浅色值。全用显式十六进制。
3. 不复用 `.article-detail__dl-btn`、`.file-btn`、`.type-filter` 这类基于变量的按钮，它们深色下失效。主按钮照 `style.css:3590` 的 `.tk-send` 写法自建。

响应式断点对齐 860 / 768 / 640，顶部加 `fade-in` 接入现有入场动画。

## 版本信息自动更新
模板内一段无依赖原生 JS，挂载后请求一次 GitHub API 的 `releases/latest`：刷新版本号、发布日期、文件大小；若最新 tag 与 front matter 版本不同且存在匹配 `-x64-setup.exe` 的资源，自动把主按钮指向新资源直链；**请求失败或无 Release 时静默保留服务端渲染的兜底内容**，按钮降级指向 Releases。首屏由 Hugo 渲染，禁用 JS 不影响可用性。
